# law-firm-theme-1

Harlan & Voss law firm website, published with GitHub Pages.

Live site: https://SaadWebsites.github.io/law-firm-theme-1/

This repository holds the built site. Page sources live in the project workspace under `themes/theme-1/_content/` and `themes/theme-1/_gen/`. Edit those, run `node _gen/run.cjs` then `node build.cjs`, and redeploy.
